# csw

Code-switching and idiom generation for 37 African languages. The project builds a multilingual corpus in which each situation is written as a standard-register translation, a natural code-switched rendering and a dense idiomatic rendering, scores it with LLM judges, and uses the resulting labels to train a generator by supervised fine-tuning and group-relative policy optimisation, with a learned quality evaluator and rule-based checks as the reward.

Documentation, paper and results are added separately.
